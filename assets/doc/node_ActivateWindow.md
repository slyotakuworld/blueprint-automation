# 🪟 ActivateWindow · 激活窗口

> 把已经打开的程序窗口提到前台~最小化的会先还原。后续键盘/鼠标等前台操作就会落进这个窗口（比如激活记事本后直接打字）。

---

## 节点外观

- **分类**：🚀 应用控制
- **配色**：紫 (#8957E5 / #A371F7)
- **短名**：`act_win`

---

## 端口

| 侧 | 类型 | 名称 | 标签 | 说明 |
|----|------|------|------|------|
| 输入 | ▶ 执行 | `in_exec` | ▶ | 上游触发后开始查找并激活窗口 |
| 输出 | ▶ 执行 | `success` | 成功 | 找到匹配窗口并置前台成功 → 走这里 |
| 输出 | ▶ 执行 | `fail` | 失败 | 找不到窗口 / 置前台失败 → 走这里（只查找一次，无超时重试） |

---

## 参数一览

| 参数名 | 编辑器 | 默认值 | 必填 | 说明 |
|--------|--------|--------|------|------|
| `target_title` | 文本 | `""` | - | 窗口标题（子串匹配即可，不用完全一样）；支持 `{变量}` 插值 |
| `target_exe` | 文本 | `""` | - | 程序名，比如 `notepad.exe`、`chrome.exe`（子串匹配）；支持 `{变量}` 插值 |
| `target_class` | 文本 | `""` | - | 窗口类名（精确匹配，不常用，用「工具 → 窗口信息拾取器」获取）；支持 `{变量}` 插值 |

> 填了的条件必须**全部**对上才算匹配成功；三个至少填一个，全空会直接走「失败」。

---

## 典型用法

### 1. 激活记事本后打字
```
title    = 无标题 - 记事本
exe_name = notepad.exe
class_name = （留空）
```
→ 激活成功后，接键盘节点即可直接往记事本里打字；接鼠标节点点击的也是前台窗口。

### 2. 只按程序名激活（不在乎标题）
```
title    = （留空）
exe_name = chrome.exe
```
→ 只要是这个 exe 开的窗口就激活，不管标题叫啥。

## 常见问题

**Q：它和「启动程序」有什么区别？**
→ 启动程序是**新开一个进程**；激活窗口是**程序已经在跑**，只是把它切到最前面。程序没开就激活不到——先启动再激活的流水线是：OpenApp → Wait(2s) → ActivateWindow。

**Q：激活成功后，找图/截图会自动对准这个窗口吗？**
→ 不会。找图/截图/鼠标等节点的「目标窗口」由**各节点自己的目标参数**决定（该节点只负责前台切换）。键盘输入和「全屏坐标」的鼠标点击则天然作用于前台窗口——这正是激活窗口的用途。

**Q：怎么知道窗口的 title/exe/class？**
→ 主界面「工具 → 窗口信息拾取器」，把十字准星拖到目标窗口上，三项全显示出来，复制粘贴到参数里。

**Q：一直 fail 找不到窗口？**
→ 标题里的空格/标点要和实际窗口一致（建议只填一段稳定的子串，比如程序名）。程序还没启动完就在前面加个 Wait 节点。

**Q：窗口最小化了能激活吗？**
→ 能。最小化的窗口会先还原（最大化的保持最大化不动，避免尺寸变化导致坐标错位）再置前台。
