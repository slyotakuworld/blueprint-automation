# 👀 IfImageDetect · 检测

> 当下就检查好几张图是不是都在屏幕上~完全求值全中才走是，短路缺一张就立马否决，一真即真（逻辑或）只要撞见任意一张中就喊是；只瞅当下这一眼，不会等太久哟。

---

## 节点外观

- **分类**：👁 视觉、感知
- **配色**：橙 (#ef6c00 / #ff9800)
- **短名**：`if_img`

---

## 端口

### 输入
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `in_exec` | ▶ 执行 | ▶ | 上游触发 |

### 输出
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `yes` | ▶ 执行 | 是 | 符合条件 → 走这里 |
| `no` | ▶ 执行 | 否 | 不符合 → 走这里 |

> 💡 **和 FindImage 的区别**：FindImage 是"在一段时间内反复重试找，找不到就算了继续往下"；IfImageDetect 是"当下瞅一眼立刻给 yes/no 判定，不重试"。FindImage 适合"必须等到按钮出现再操作"，IfImageDetect 适合「当前界面是不是这个页面？」做条件分支判断。

## 参数一览

| 参数 | 编辑器 | 默认值 | 说明 |
|------|--------|--------|------|
| `match_strategy` | 下拉 | `hybrid` | 匹配算法：智能混合 / 模板 / 灰度 / 特征（同 FindImage） |
| `search_mode` | 下拉 | `relative` | 检测范围：相对目标程序 / 全屏模式 |
| `temp_target_title` | 文本 | `""` | 仅相对模式：临时目标窗口标题 |
| `temp_target_exe` | 文本 | `""` | 仅相对模式：临时目标程序名 |
| `temp_target_class` | 文本 | `""` | 仅相对模式：临时目标窗口类名 |
| `threshold` | 小数 | `0.9` | 匹配阈值（0.3~1.0），全代码层统一默认 0.9 |
| `eval_mode` | 下拉 | `complete` | 求值模式：完全求值 / 短路模式 / 一真即真 |
| `images_json` | 文本 | `"[]"` | 参考图列表 JSON 数组；Inspector 中提供可视化 UI，不用手填 |

> 💡 **临时目标窗口 与「📷 截图新增一张」联动**：若已拾取临时目标窗口，截图时框选范围会
> 自动限定在该窗口内（窗口外点不进去、拖到边界自动贴边）。找不到该窗口时回退为全屏框选。

## 三种求值模式 eval_mode

| 模式 | 逻辑 | 说明 |
|------|------|------|
| **complete 完全求值** | AND 全匹配 | 不管中间有没有失败，所有参考图都会检测一遍，日志输出每张得分（便于调试）；全部匹配才走 yes。**默认模式。** |
| **short_circuit 短路模式** | AND 一假即假 | 从左到右依次检测，只要有一张不匹配 → 立刻返回 no，省时间 |
| **or_true 一真即真** | OR 一真即真 | 任意一张匹配成功 → 立刻返回 yes；全部都不匹配才走 no |

> ⚠ 完全模式下，如果**没有添加任何参考图**（空集），将直接走「否」分支。

## 可视化添加参考图

不用手填 images_json，属性面板里有专门的 UI：

1. 点「➕ 添加检测图」
2. 每个检测图都有自己的缩略图、模板路径、独立阈值（可选，没填就用节点全局 threshold）
3. 每个检测图都能点「📸 截取」或「📂 导入」选图
4. 可以点「上移/下移」调整检测顺序（对短路/一真即真模式有意义）
5. 点「🗑 删除」去掉某一张

images_json 里面每一项结构示例：
```json
[
  {"b64":"...(base64缩略图)...","w":120, "h":40, "path":"D:/templates/btn_a.png"},
  {"b64":"...","w":80,"h":30,"path":"D:/templates/btn_b.png","threshold":0.95}
]
```

## 典型用法

### 1. 判断当前是不是「游戏主菜单」页面
完全模式 AND，页面上三个按钮都有才走 yes：
```
IfImageDetect：
  eval_mode = complete（完全求值，三张全中才算 yes）
  参考图：
    ① 「开始游戏」按钮模板
    ② 「设置」按钮模板
    ③ 「退出」按钮模板

连线：
  yes → 说明在主菜单 → 点击开始游戏
  no  → 可能在登录界面 → 其他处理
```

### 2. 三种弹窗任意出现一种就点关闭（OR 逻辑）
```
IfImageDetect：
  eval_mode = or_true（一真即真）
  参考图：
    ① 「每日签到」关闭按钮
    ② 「活动公告」关闭按钮
    ③ 「版本更新」关闭按钮

连线：
  yes → 有弹窗 → 用 Sequence(or_true) 找对应按钮点掉
  no  → 没弹窗 → 跳过
```

### 3. 快速判断某个提示有没有弹出来（短路省时间）
```
IfImageDetect：
  eval_mode = short_circuit
  参考图：①「提示-体力不足」②「提示-背包已满」
```
→ 体力不足那张一出来就立刻判定 yes，不用等背包已满也检测一遍，省时间。

## 常见问题

**Q：为什么 FindImage 有重试/超时，IfImageDetect 没有？**
→ 定位不同：FindImage 是「等出现」；IfImageDetect 是「当下判断」。如果想「等 5 秒看会不会出现」，用 Loop 包一层 IfImageDetect，yes 就 break，5 秒超时走 no。

**Q：20 张图同时检测会不会特别慢？**
→ 会。建议一屏内一次检测控制在 5~8 张以内，或者用短路/一真即真模式尽早退出。检测时间 ≈ 张数 × 单张平均耗时。

**Q：images_json 是字符串还是数组？**
→ 节点参数里存的是**字符串化的 JSON**（因为 ParamDef 里 EDITOR_STRING）；运行时内部会解析成 list，解析失败就视为空数组 []，不会报错。
