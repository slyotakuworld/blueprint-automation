# 🍎 软件介绍

## 🐺 赫萝蓝图自动化是什么？

赫萝蓝图自动化是一款**可视化节点式自动化工具**，通过拖拽节点、连线的方式，就能编写出复杂的自动化脚本，无需手写一行代码 🍎

就像拼乐高一样，把「启动程序 → 找图点击 → 输入文字 → 等待」这些积木块拼在一起，就能让电脑自动帮你完成重复性工作！

---

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🎨 **可视化蓝图** | 拖拽节点 + 连线，零基础也能上手 |
| 👁 **图像识别** | 找图/多图检测/静止检测/声音检测，四大感知节点 |
| 🖱 **键鼠模拟** | 真实拟人化鼠标键盘操作，防检测 |
| ⌨ **全局热键截图** | 游戏内也能一键截图，无缝对接找图节点 |
| 🔁 **循环/条件** | 完整的逻辑控制，循环、分支、变量统统有 |
| 🌐 **网络请求** | HTTP 接口调用、命令行执行、浏览器启动 |
| 📦 **导出独立 EXE** | 一键把蓝图打包成可脱离本项目单独运行的挂机程序 |

---

## 🎯 适合做什么？

- 🎮 **游戏辅助**：自动刷图、日常任务、连点宏、挂机脚本
- 📋 **办公自动化**：批量填表、数据录入、报表生成
- 🧪 **软件测试**：UI 自动化测试、回归测试
- 🖼 **图像识别工作流**：批量找图、截图比对、OCR 前置处理
- 🔧 **任何重复劳动**：只要是你每天重复点的操作，都能交给赫萝！
