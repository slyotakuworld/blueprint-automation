# ❓ 基础使用 FAQ

> 第一次接触蓝图工具？这里整理了新手最常问的 10 个问题。

---

### Q1：这个工具是做什么的？

**A**：一个「画流程图式的」自动化工具。用节点+连线搭流程，不用写代码就能让电脑帮你完成：
- 自动打开软件、绑定窗口
- 自动找图、按快捷键、鼠标点击
- 打开浏览器访问网页、HTTP 请求拿数据
- 循环、分支、变量判断

适合：游戏日常挂机、软件重复操作、桌面 RPA、批量任务。

---

### Q2：需要写代码吗？

**A**：完全不需要。所有逻辑都是「拖节点 → 连线 → 填参数」。

只有在以下场景会接触到一点点极简单的语法：
- `SetVariable` 的「批量设置」里写 `hp = {= hp + 1}` 这种算术表达式（用 `{= ...}` 包住算式）
- 参数里写 `{变量名}` 引用变量
- 都非常简单，文档里都有例子照抄就行 🍎。

---

### Q3：蓝图和脚本的区别？

| 方式 | 上手难度 | 可视化 | 调试 | 修改 |
|------|---------|--------|------|------|
| 脚本（Python/AHK） | 需要学编程 | ❌ | 加 print/log | 改代码重跑 |
| **蓝图像咱** | ✅ 几乎零基础 | ✅ 连线一眼看到底 | ✅ 节点状态一眼看出来 | ✅ 节点上改值立即生效 |

→ 复杂场景（1000 行代码那种）还是建议脚本。但几十到几百步的自动化流程，蓝图做起来快 10 倍。

---

### Q4：支持哪些操作系统？

**A**：目前只在 Windows 10/11 64 位上完全测试通过。

底层依赖：
- pywin32（窗口控制、进程）
- win32gui / win32con（窗口消息）
- pyautogui（键鼠、屏幕截图）

所以：**必须 Windows**。Mac/Linux 暂不支持（你可以编译环境配好，但很多节点不能用）。

---

### Q5：怎么启动第一个蓝图？

**A**：步骤很简单：
1. 打开蓝图编辑器
2. 左侧节点库拖一个 `Start` 到画布
3. 再拖一个 `Notify` 到画布
4. 连线：`Start.out_done ▶` → `Notify.in_exec ▶`
5. 在 Notify 的 `text` 参数里写「赫萝测试成功~ 🍎」
6. 点工具栏的 ▶ 运行按钮（或按运行快捷键，默认F5）跑起来 🐺

 应该能看到一个 toast 弹出来：「赫萝测试成功~」🍎

---

### Q6：运行 / 暂停 / 停止快捷键都是啥？

咱给苹果商人列清楚 🐺：

| 快捷键 | 作用 |
|--------|------|
| 运行快捷键（默认F5） | 运行（从起点 Start 开始跑） |
| 暂停快捷键（默认F6） | 暂停 / 继续（蓝图还在内存里，随时接着跑） |
| 停止快捷键（默认F7） | 停止（立刻结束，所有 Loop 都退出） |

工具栏上也有对应的三个按钮：▶ ⏸ ⏹

### Q7：蓝图文件保存在哪里？

**A**：蓝图保存在你当前打开的项目文件夹下的 `blueprints/` 子目录里：
```
<你的项目文件夹>\blueprints\你的蓝图名.json
```

也可以在编辑器 → 文件 → 另存为，选任意位置保存。文件格式是纯 JSON，可以用文本编辑器打开、复制、备份 🍎。

---

### Q8：怎么让蓝图一开机就自动跑？

**A**：工具本身不带自启动，但可以用 Windows 自带的：
1. 右键「开始菜单」→ 运行 → 输入 `shell:startup` → 回车
2. 在打开的文件夹里新建一个 `.bat` 文件：
```bat
@echo off
cd /d g:\work\BlueprintAutomation
python src/blueprint_app.py
```
启动后会打开编辑器，苹果商人点 ▶ 运行按钮就能让蓝图跑起来 🐺。

或者更稳的方式：Windows 任务计划程序（taskschd.msc），指定「登录时」触发。

### Q9：我想把自动化结果发送到微信 / 钉钉 / 企业微信？

**A**：用 HttpRequest 节点。各家都有 Webhook：
- 钉钉群机器人：`POST https://oapi.dingtalk.com/robot/send?access_token=xxx`
- 企业微信群机器人：`POST https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx`
- Server 酱（推到微信）：`POST https://sctapi.ftqq.com/xxx.send`

body JSON 按照各平台文档格式写。详细示例参考 [HttpRequest 节点文档](file:///g:/work/BlueprintAutomation/config/doc/node_HttpRequest.md) 里的「典型用法」一节。
