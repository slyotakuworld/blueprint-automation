# 🔧 节点操作

## 添加节点

3 种方式：
1. **拖拽**（最常用）：从左侧节点库点住节点 → 拖到画布 → 松开
2. **右键画布** → 「添加节点」→ 从子菜单选
3. **快速搜索**：画布顶部搜索栏，快捷键 Ctrl+F 聚焦

---

## 选中 & 多选

| 操作 | 效果 |
|------|------|
| 单击节点 | 选中单个节点（黄色描边高亮） |
| Shift + 单击 | 追加选中 / 取消选中单个 |
| 框选 | 拉框批量选 |

选中节点后：
- 右侧属性面板显示该节点的所有参数
- **该节点所有出去的线条会高亮**（方便看数据流流向）

---

## 移动节点

- 左键点住节点拖 → 移动单个
- 选中多个后拖其中任意一个 → 整体移动
- 方向键微调（1 像素每次）

> 💡 拖动节点时，连在节点上的所有线条会**自动刷新位置**，不用手动重新连~

---

## 复制粘贴删除

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 复制 | Ctrl+C | 复制选中节点到剪贴板 |
| 粘贴 | Ctrl+V | 粘贴（新节点会偏移一点位置，避免重叠） |
| 删除 | Delete / Backspace | 删除选中的节点和相连的线 |

> ⚠ 删除的节点和线，**Ctrl+Z 可以完整恢复**，放心删~

---

## 右键节点菜单

在节点上点右键：
- **复制 / 剪切 / 删除**
- **重命名节点**（修改画布上显示的标题，方便读图）
- **禁用节点**（运行时跳过，相当于注释掉）
- **导出为模板**（把这个节点+参数存成模板，下次一键拖入）
- **连线相关操作**：端口右键 → 「解除所有连线 (N 条)」

---

## 禁用 / 启用节点

选中节点后点右键 → **禁用节点**：
- 该节点会变成半透明灰色
- 运行时**直接跳过**（输入输出都不执行）
- 相当于代码里的注释掉
- 再次右键 → 启用节点，恢复原样

调试蓝图非常好用：某个节点有问题，先禁用它，确认其他部分正常后再单独查它 🍎
