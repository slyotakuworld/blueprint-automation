# ⏳ Wait · 等待

> 歇会儿再接着跑~要么固定睡几秒，要么在范围内随机小睡更像真人，上游传过来的秒数也能直接拿来用哟。

---

## 节点外观

- **分类**：🎯 动作
- **配色**：灰 (#2D333B / #8B949E)
- **短名**：`wait`

---

## 端口

### 输入
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `in_exec` | ▶ 执行 | ▶ | 上游触发 |
| `in_seconds` | ○ 数据 (float) | 秒数 | **非空时优先用这个值**，覆盖参数里的 seconds/min/max；必须是浮点或整数 |

### 输出
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `out_exec` | ▶ 执行 | ▶ | 时间到了 → 往下走 |

---

## 参数一览

| 参数 | 编辑器 | 默认值 | 说明 |
|------|--------|--------|------|
| `delay_type` | 下拉 | `fixed` | `fixed` 固定延时 / `random` 随机延时（更拟人） |
| `seconds` | 小数 | `1.0` | 【fixed模式】等待秒数（0.0 ~ 3600 秒，1 小时上限） |
| `min_seconds` | 小数 | `1.0` | 【random模式】随机范围下限秒 |
| `max_seconds` | 小数 | `3.0` | 【random模式】随机范围上限秒 |

---

## 两种模式详解

### 1️⃣ fixed（固定延时）
```
delay_type  = fixed
seconds     = 2.5
```
→ 每次运行都**精确等 2.5 秒**。

适用场景：
- 程序启动必须等够时间（比如启动必须等 5 秒游戏才会进入主菜单）
- 截图间隔（每隔 10 秒截图一次）

### 2️⃣ random（随机延时，推荐日常用）
```
delay_type  = random
min_seconds = 1.0
max_seconds = 3.0
```
→ 每次在 1.0~3.0 秒之间取一个随机值（每次不一样）。

适用场景：
- 游戏内操作之间的间隔（真人不可能每次都精确卡1秒一按，容易被检测）
- 浏览、点击、翻页等非关键操作

## 输入端口优先级（重要！）

```
优先级 #1 最高：in_seconds 数据端口非空（含 0）→ 用端口值，忽略参数
优先级 #2：     用参数 seconds / min_seconds / max_seconds
```

⚠ 端口连了线就一律以端口值为准（连 0 也算"有值"，实际就不等待）。想让参数生效就别连 `in_seconds`。

比如 FindImage 找图超时设置是 10 秒，但找到了就想立刻点下一个节点中间加个小延迟：
```
FindImage → in_seconds 不连线，用参数 Wait(seconds=0.3)
```

如果某个节点输出了要等的时间（比如 HTTP 接口返回了 `retry_after=5` 秒）：
```
VarSwitch 里算出来的 retry_after（绿色 float）→ Wait.in_seconds
→ Wait 节点忽略参数，实际就等 retry_after 那么久
```

> 💡 也支持把 Wait 节点放一个在 Loop 里做「每 X 秒执行一次」的控制循环间隔。

## 典型用法

### 1. 程序启动后等待加载
```
OpenApp(打开游戏) → Wait(seconds=15, fixed) → FindImage(进入游戏按钮)
```
→ 必须等够 15 秒让游戏加载完，再开始找图/操作。

### 2. 两次点击之间小睡（拟人）
```
Mouse(点A) → Wait(random 0.2~0.6) → Mouse(点B) → Wait(random 0.2~0.6) → Mouse(点C)
```
→ 点击间隔随机，看起来不像机器人 🐺

### 3. 等通知读秒（简单节拍器）
```
Loop(infinite)
  loop_body → 日常任务链路
  Wait(fixed 30)  ← 每 30 秒跑一圈日常
```
→ 每 30 秒检查一次。

## 常见问题

**Q：最小可以设 0 吗？**
→ 可以，`seconds = 0` 就等同于啥也不做、立刻走 out_exec（不报错，只是没意义）。

**Q：Wait 节点能暂停吗？**
→ 蓝图全局暂停后 Wait 也会停住，倒计时暂停多长时间就延长多长，不会把暂停时间算在等待时长里扣掉。
