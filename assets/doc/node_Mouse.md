> 鼠标交给咱啦~点击、按住、释放、移动、拖拽、滚轮随便选，坐标既能去屏幕上点着选，也能从上游找图节点直接连线传过来更省心哟。

## 端口

### 输入
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `in_exec` | ▶ 执行 | ▶ | 上游触发 |
| `in_pos` | ○ 数据 (tuple2) | 坐标(来自FindImage) | 从 FindImage.out_pos 连线过来；**非空时覆盖参数里的 pos** |

### 输出
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `out_done` | ▶ 执行 | 完成 | 鼠标动作执行成功 → 走这里 |
| `err` | ▶ 执行 | 失败 | 执行出错（含**坐标基准=目标窗口但没定位到窗口**）→ 走这里 |

## 参数一览

| 参数 | 编辑器 | 默认值 | 说明 |
|------|--------|--------|------|
| `range_mode` | 下拉 | `window` | **坐标基准**：`window` 目标窗口 / `fullscreen` 全屏 |
| `target_title` | 文本 | `""` | 仅「目标窗口」模式生效：窗口标题子串（支持 `{变量}`）；点「🎯 拾取目标窗口」可自动填 |
| `target_exe` | 文本 | `""` | 仅「目标窗口」模式生效：程序名子串 |
| `target_class` | 文本 | `""` | 仅「目标窗口」模式生效：窗口类名精确匹配 |
| `action` | 下拉 | `click` | 动作类型：click 点击 / move 移动 / drag 拖拽 / scroll 滚动 |
| `pos` | tuple2 | `(0,0)` | 目标点坐标 (X, Y)，点 📍 按钮可屏幕拾取 |
| `from_pos` | tuple2 | `(0,0)` | 【drag 独有】拖拽起点坐标，点 📍 拾取 |
| `to_pos` | tuple2 | `(0,0)` | 【drag 独有】拖拽终点坐标，点 📍 拾取 |
| `drag_duration_ms` | 整数 | `300` | 【drag 独有】拖拽时长 ms；0=瞬间，越大越平滑 |
| `button` | 下拉 | `left` | left 左键 / right 右键 |
| `click_count` | 整数 | `1` | 1=单击 2=双击 3=三击 |
| `hold_ms_min` | 整数 | `30` | 按下保持最小毫秒数 |
| `hold_ms_max` | 整数 | `80` | 按下保持最大毫秒数（最小=最大则固定；否则随机更像真人） |
| `post_delay_min_ms` | 整数 | `30` | 操作后最小延迟 |
| `post_delay_max_ms` | 整数 | `80` | 操作后最大延迟（随机=拟人） |
| `scroll_dy` | 整数 | `400` | 【scroll 独有】滚动距离（像素）：正=滚轮向前(页面上滚)，负=向后(下滚)；按经验 400≈1页 |
| `scroll_steps` | 整数 | `1` | 【scroll 独有】重复滚动次数 |

## 坐标基准（非常重要！）

### window 目标窗口（推荐）
- 所有坐标 = **相对目标窗口左上角 (0,0)** 的偏移量
- 窗口移动位置 → 点击点跟着移动（自动换算）
- 窗口大小变化 → 按配置的分辨率做归一化
- 窗口从哪来：本节点自己的「目标窗口」定位参数（`target_title` / `target_exe` / `target_class`，**至少填一个**）
- ⚠ 定位不到窗口 → 直接走 `err`（失败），**不会按绝对坐标硬点**（那会点到屏幕别处去）
- 适合：游戏窗口、固定布局的软件界面

### fullscreen 全屏（绝对屏幕坐标）
- 坐标 = 屏幕左上角 (0,0) 算
- 目标窗口一旦换位置就点错地方
- 适合：任务栏图标、桌面图标这种位置固定的东西

> 📌 **要和上游找图节点配对**：FindImage 的「找图范围」= 目标窗口时，输出的是相对窗口坐标，那 Mouse 这边「坐标基准」也要选**目标窗口**；FindImage 用「全屏」时，Mouse 也选**全屏**。两边口径不一致就会点偏。

## 四种动作详解

### 1️⃣ action = click（点击）
```
pos = (X, Y)            ← 点 📍 去屏幕上选
button = left / right
click_count = 1 / 2 / 3
```
→ 移动到 pos → 按下 → 保持 hold_ms → 释放 → 等 post_delay

### 2️⃣ action = move（移动）
```
pos = (X, Y)
```
→ 只移动鼠标到目标点，不点击也不按键。
→ 用途：拖拽前先移动到某个位置、让鼠标悬停在按钮上触发 tooltip 等。

### 3️⃣ action = drag（拖拽）
```
from_pos        = 起点坐标
to_pos          = 终点坐标
drag_duration_ms = 300  ← 越大越平滑，0=瞬间拖过去
```
→ 移动到起点 → 按下 button → 以平滑速度拖到终点 → 释放

### 4️⃣ action = scroll（滚动）
```
pos = (滚到屏幕上这个位置再滚，通常把 scroll_dy 放中间就好)
scroll_dy    = 400      ← 正=向前(页面/视角向上滚)，负=向后(页面/视角向下滚)
scroll_steps = 1        ← 滚几次
```

> ⚠ **注意正负方向（跟 pyautogui 行为一致）**：
> - scroll_dy **正值** = 滚轮向前转 → 页面视角**向上**滚动（内容往下移）
> - scroll_dy **负值** = 滚轮向后转 → 页面视角**向下**滚动（内容往上移）
> - 浏览器常见 1 格 ≈ 40 像素，400 ≈ 滚 1 页

## 从 FindImage 节点传坐标（最常用的搭配！）

不用点 📍 手选，让 FindImage 找到位置后自动点：

```
FindImage.out_pos (绿色圆圈 tuple2) → Mouse.in_pos
FindImage.found   (绿色三角)       → Mouse.in_exec
```
→ 两边都选「目标窗口」（或都选「全屏」）保证口径一致。
→ FindImage 找到了 → 触发 Mouse → 点在 FindImage 输出的坐标上，**参数里的 pos 自动被覆盖**不用改。
→ ⚠ **触发口一定要连 `found`，别连 `out_exec`**：`out_exec` 是「找没找到都触发」，没找到时 `in_pos` 是空的，Mouse 会退回去点参数里那个固定坐标 —— 那就点到别处去了。
→ 再给 FindImage 的「找到后执行」选左键单击也行（两个效果等价，选哪个都行）。

## 拟人化操作设置（防检测！）

以下几个参数是给"避免被当成机器人"准备的，默认就很合理：
- `hold_ms_min` ~ `hold_ms_max`：按下保持时间不要每次都一样
- `post_delay_min_ms` ~ `post_delay_max_ms`：操作完了稍微等一会儿
- 两项的上下限不要设成一样的，保持 30~80 这种区间，每次都是随机值，更像真人

## 常见问题

**Q：FindImage 传了坐标，还需要在 Mouse 里填 pos 吗？**
→ 不需要，连线后 in_pos 非空就覆盖 pos。但建议填一个大概位置，离线读图的时候有个参考。

**Q：坐标基准选了「目标窗口」，但窗口没开，会怎样？**
→ 直接走 `err`（失败）。**不会**退化成按绝对坐标去点——那等于乱点屏幕，比失败更糟、更难查。请用 err 出口做异常处理（记录/提示/重启程序）。

**Q：点 📍 拾取不到游戏内坐标？**
→ 有些全屏游戏会屏蔽截图。解决办法：开无边框窗口化（borderless windowed），在游戏窗口化的时候先拾取坐标。

**Q：拖拽速度不对？**
→ 调 `drag_duration_ms`，100=飞快、300=自然、800=慢慢拖。
