# 🎨 画布操作

## 缩放与平移

| 操作 | 效果 |
|------|------|
| 鼠标滚轮 | 以鼠标位置为中心缩放画布 |
| 按住 **鼠标中键** 拖动 | 平移画布（画布内容跟着动） |
| 鼠标**中键**拖动 或 **右键**在空白处拖动 | 平移画布 |
| 滚轮 | 缩放（每格约 15%） |

### 工具栏
- 「缩放适应」和「重置 100%」两个按钮
- **重置视图**：100% 缩放，画布回到左上角
- **适应窗口**：让所有节点都在视口内显示（没内容时无效）

---

## 框选节点

- 按住鼠标左键在画布空白处拖动 → 拉出一个虚线框
- 被框住的节点会整体被选中（黄色高亮框）
- 按住 **Shift** 再框选 → 追加选中（不会取消之前选的）
- 按住 **Ctrl** 再框选 → 取消选中（反选）

---

## 多节点操作

选中多个节点后可以：
- 按 **方向键** → 整体微调位置（每次 1 像素，精细对齐好用）
- 按住左键拖动 → 整体移动
- Ctrl+C / Ctrl+V → 整体复制粘贴（新节点 id 会自动生成新的）
- Delete → 整体删除（连线也会一起删，撤销能恢复）

---

## 画布右键

画布空白处右键拖动 = 平移画布，不弹出上下文菜单。粘贴通过 Ctrl+V 全局快捷键。

---

## 小贴士 🐺

1. **蓝图越大越要命名**：节点多了以后，给每个重要节点起个名字（属性面板里可以改节点显示名），不然三个月后回来自己都看不懂
2. **用注释节点**（未来版本）：复杂的逻辑分支旁边加个注释，写清楚这段在干嘛
3. **不要所有东西都塞一张蓝图**：功能独立的模块拆成多张蓝图，用「子蓝图」或变量传参组合起来（未来版本支持子蓝图节点）
