# ▶️ 运行与调试

## 运行蓝图

3 种方式开始执行：
1. 工具栏 **▶ 绿色播放按钮**
2. 菜单 **运行 → 运行**
3. 工具栏 **▶ 运行** 按钮（或运行快捷键，默认F5）

### 运行中你会看到
- 正在执行的节点 → **绿色高亮脉冲动画**
- 执行完成的节点 → **绿色对勾标记**
- 执行失败的节点 → **红色 X 标记**
- 底部日志面板 → 实时打印每个节点的开始 / 结束 / 输出

## 暂停 & 停止

| 操作 | 快捷键 | 效果 |
|------|--------|------|
| ⏸ 暂停 | 可配置（默认F6） | 暂停在当前节点，再点一次继续往下跑 |
| ⏹ 停止 | 可配置（默认F7） | 立刻终止，所有节点都停（不会继续往下走） |

> 💡 正在循环里跑的蓝图，按停止后，下一次运行会从 Start 重新开始。

---

## 从指定节点开始运行

调试时不想每次都从头跑？

1. 在要开始的节点上点右键
2. 选 **「从该节点开始运行」**
3. 前面的节点会被跳过，直接从选中的节点开始执行

> ⚠ 注意：前面节点设置的变量不会自动生成，建议先用 SetVariable 设置好需要的变量，再从指定节点开始。

## 断点调试（类似 Debug）

在节点上点右键 → **「切换断点」**：
- 节点左上角会出现一个**红点**
- 运行到该节点前会**自动暂停**
- 此时可以去看变量值、日志、截图结果
- 确认没问题后，点⏸继续往下跑，或者点■停止

可以在多个节点上加断点，蓝图会在每个断点处依次停住。

**断点的作用范围**：根画布、循环体、顺序体（子画布）里的节点都可以打断点 ——
运行到那里时画布会**跟着钻进对应的子画布**并停在断点节点上；循环体里的断点**每一轮都会命中**。
唯一例外是**并行体**：默认是调试黑盒（断点请打在「并行执行」节点本身）；如果勾上了并行节点的
「**调试主线程**」参数，则**主线程分支**里的节点也支持断点/单步/高亮（画布会跟进并行体），
且调试暂停**不会**停住其它分支——适合「一个分支跑主逻辑 + 一个分支跑守护/保活」的调试。

## 一个出口连多条线（fan-out）怎么执行

一个节点的 ▶ 出口连了**多条线**时，这些线都会被执行（不会漏），顺序规则：

1. **按连线的「优先级权重」降序**：右键任意连线 → 设置权重（默认 1），**权重大的先执行**；
   线上会显示「权重N」徽标，改权重支持 Ctrl+Z 撤销。
2. **权重相同按连线先后**（本次编辑会话内的连线顺序）。
3. 两条线各带一条链时是**逐层交替**执行：`a → b → a1 → b1 → a2 → b2`（不是先跑完 A 链再跑 B 链），
   每条链内部顺序不变。

⚠ 优先级权重只影响**执行先后**，不影响结果；只连一条线时权重没有意义。
需要严格「先做完 A 再做 B」的流程，请直接串成一条线（A → B），比权重更直观。

## 日志面板怎么看

底部日志面板 4 种颜色：

| 颜色 | 级别 | 含义 |
|------|------|------|
| ⚪ 白色（灰色背景） | INFO | 普通信息（节点开始/结束、常规日志） |
| 🟡 黄色 | WARN | 警告（不会中断执行，但可能有问题） |
| 🔴 红色 | ERROR | 错误（节点执行失败，看看走哪个分支了） |
| 🔵 蓝色 | DEBUG | 调试（找图得分、变量值变化等细节） |

### 日志里常见的信息

**找图节点执行后**：
```
[FindImage] 匹配策略: 智能混合 | 使用灰度匹配成功 | 得分: 0.952 | 位置: (412, 305)
```
→ 你就知道：用了哪一层算法、相似度多少、坐标在哪。

**命令节点执行后**：
```
[Command] exit_code=0
stdout:
  <标准输出内容>
stderr:
  <错误输出内容>
```

## 常见调试技巧

### 1. 拆一半验证
蓝图很长失败了，不知道哪个节点出问题？
- 从中间加一个 End 节点，先跑前一半
- 前一半没问题，再把 End 往后挪，缩小排查范围

### 2. 禁用节点当注释
选中节点 → 右键 → **禁用节点**：
- 节点变灰，运行时跳过
- 不用真的删掉，方便试错对比

### 3. Notify 打印变量
关键节点后面插一个 Notify：
- 内容写 `{ALL_VARS}`
- 勾选「系统弹窗」
- 运行到这里立刻看到所有变量

### 4. 先小范围再扩展
- 先把「找图→点击」这一段单独拿出来测通
- 确认找图阈值、坐标都对了，再拼到主蓝图里
- 比一上来拼好几十米长的蓝图再调试，效率高很多 🍎
