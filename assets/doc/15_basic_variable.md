# 📦 变量系统

## 变量是什么？

变量就是一个带名字的「小盒子」，盒子里存着值（数字、文本、坐标、真假都可以）。

```
变量名 hp = 100          ← 存了个数字
变量名 player = "赫萝"    ← 存了段文字
变量名 score >= 60       ← 条件判断里可以直接用
```

变量的好处：
1. **一处改处处用**：比如把「等待时间」存变量 `wait_sec = 2`，后面 50 个 Wait 节点都写 `{wait_sec}`，改一次变量就全改了
2. **节点之间传值**：Command 输出 → 存变量 → VarSwitch 判断退出码
3. **动态计算**：表达式里可以做加减乘除

## SetVariable 节点：设置变量

最常用的节点之一，每行写 `变量名 = 值`。

### 基础写法
```
# 数字
hp = 100
count = 0

# 文本（可以不加引号，但加了更清晰）
name = 赫萝
hero = "贤狼赫萝"

# 真假
is_open = true
has_flag = false
```

### 引用别的变量
```
base = 100
bonus = 50
total = {= {base} + {bonus}}   ← {= ...} 里写表达式做计算
```

### 多数据输入端口用法
1. 先把上方「数据输入端口数」调大（比如 2）
2. SetVariable 节点左侧会多出 2 个绿色数据输入端口
3. 上游节点（比如 Command 的 stdout）连线过来
4. 批量设置里用 `__INPUTS__0`、`__INPUTS__1` 取每个端口的值

```
# 第 1 个输入端口连了 Command.stdout
cmd_out = {__INPUTS__0}

# 第 2 个输入端口连了 Clipboard.out_text
clip = {__INPUTS__1}

# 做计算
len = {= len({__INPUTS__0})}
```

> ⚠ **重要**：SetVariable 里写 `name = "苹果"`，引号不会被剥掉，会**连同引号一起存进去**！
> 如果不想要引号，直接写 `name = 苹果`。

## 变量插值：哪里可以写 `{变量名}`？

几乎所有文本类参数都支持变量插值。常见写法：

| 写法 | 含义 |
|------|------|
| `{hp}` | 取变量 hp 的值 |
| `${hp}` | 同上，花括号加美元符号（兼容另一种风格） |
| `{= {hp} + 1}` | 先取 hp 的值，加 1 后整体作为结果 |
| `{= int({a}) + int({b})}` | Command.stdout 之类的文本，先转成数字再计算 |
| `{ALL_VARS}` | 一次性展开所有变量（调试用） |

### 实际例子

**Wait 节点的秒数参数**：写 `{wait_sec}` → 运行时自动替换成变量值

**PressKey 输入文本**：写 `你好呀，{player}！` → 运行时变成 `你好呀，赫萝！`

**HttpRequest 的 URL**：写 `https://api.example.com/user?id={user_id}` → 拼接变量

**Notify 通知**：写 `血量只剩下 {hp} 了！` → 弹窗会带实时数值

## VarSwitch 节点：条件判断

### 标准写法（每行 变量名 运算符 值）
```
hp >= 30
hp <= 100
score >= 60
level > {min_level}
```

全部条件都满足 → 走 **满足（yes）** 分支
只要有一条不满足 → 走 **不满足（no）** 分支

### 支持的运算符
| 运算符 | 含义 | 例子 |
|--------|------|------|
| `==` | 等于 | `status == "ok"` |
| `!=` | 不等于 | `result != "fail"` |
| `>`  | 大于 | `score > 60` |
| `<`  | 小于 | `hp < 30` |
| `>=` | 大于等于 | `lv >= 10` |
| `<=` | 小于等于 | `time <= 30` |

### 简写语法（连了 in_0 数据端口时）
行首直接写运算符，左值自动等于 `__INPUTS__0`（第一个输入端口）：
```
== 1              ← 意思：第1个输入 == 数字1
== {id}           ← 意思：第1个输入 == 变量id
>= {min_score}    ← 意思：第1个输入 >= 变量min_score
```

### 多输入端口写法（完整版）
```
__INPUTS__0 >= {min_score} AND __INPUTS__1 != {exclude_status}
```

> ⚠ **数值比较注意**：比较运算符 `> < >= <=` **只支持数字**！比较的两个值里有不是数字的，直接返回 False。如果是字符串比较，用 `==` / `!=`。

## 调试变量：Notify 一键打印

不确定变量值对不对？拖一个 **Notify** 节点：
- 内容里写 `当前变量状态：{ALL_VARS}`
- 勾选「系统弹窗」
- 运行到这里就会弹出所有变量的名字和值，一目了然 🍎
