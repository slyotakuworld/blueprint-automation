# ⌨️ PressKey · 按键

> 键盘交给咱~要么输入一段文字（还能用剪贴板粘贴防乱码、末尾按回车），要么按组合键（ctrl+c、alt+f4这种，还能重复按好几次）。

---

## 节点外观

- **分类**：🎯 动作
- **配色**：红 (#B62324 / #FF7B72)
- **短名**：`keyboard`

---

## 端口

### 输入
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `in_exec` | ▶ 执行 | ▶ | 上游触发 |
| `in_text` | ○ 数据(str) | 文本内容(连线优先) | **两种模式下都固定存在**（切模式不会消失、不会断线）。用来接上游节点拿到的文字（文字识别结果、命令输出、变量…），「输入文本」模式下直接把它敲进目标窗口；「按键组合」模式不使用它，连了也不生效——但线会保留，切回「输入文本」立刻又能用。 |

### 输出
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `out_exec` | ▶ 执行 | ▶ | 执行完 → 触发下游 |

---

## 参数一览

| 参数 | 编辑器 | 默认值 | 说明 |
|------|--------|--------|------|
| `kb_mode` | 下拉 | `text` | 模式：`text` 输入文本 / `key` 按键组合 |
| `text` | 多行文本 | `""` | 【text模式】手写要输入的文字，支持 {var} 变量插值；若左侧「文本内容」端口连了线且值非空 → 优先用连线值 |
| `use_paste` | ✅ 复选 | `true` | 【text模式】勾选=用剪贴板粘贴（快速、防中文乱码）；不勾=逐字符按键输入 |
| `press_enter` | ✅ 复选 | `false` | 【text模式】输入完文本后再按一次回车键 |
| `key_combo` | 文本 | `"[]"` | 【key模式】按键数组JSON，如 `["ctrl","c"]`。通过面板下拉框选，不用手填 |
| `count` | 整数 | `1` | 【key模式】重复按几次（1~1000） |
| `hold_ms` | 整数 | `50` | 【key模式】每次按下保持时间 ms（1~5000） |
| `interval_ms` | 整数 | `100` | 【key模式】重复按键之间的间隔 ms |

## 模式一：text（输入文本）

### 内容从哪来？两种来源，二选一

| 来源 | 怎么用 | 支持 {var} 插值？ |
|------|--------|-------------------|
| **参数「文本内容」** | 右侧属性面板里手写常量 | ✅ 支持 |
| **左侧「文本内容」端口** | 从上游节点连线传进来（识别结果 / 命令输出 / 变量节点…） | ❌ 不插值——上游给什么就敲什么，它本身就是最终值 |

**优先级：端口 > 参数。** 端口连了线且值非空 → 用端口值，参数里写的内容被忽略；端口没连线、或值为空 → 用参数。
（仅「输入文本」模式适用；「按键组合」模式完全不看端口和这个参数。）

> 画布摘要会跟着变：参数为空且端口有连线时显示 `[输入文本] [粘贴] ← 端口传入`；连端口也没连则显示 `(空)`。
> 两种来源都拿不到内容时，节点不输入任何东西，只打一条 WARN 日志后继续走 `out_exec`。

### 变量插值怎么写（参数「文本内容」）

| 写法 | 含义 | 例子 |
|------|------|------|
| `{变量名}` | 取变量值 | `你好，{user_name}` |
| `${变量名}` | 同上，写法更明确 | `你好，${user_name}` |
| `{= 表达式 }` | 先算表达式再填 | `第 {= count + 1 } 关` |

变量来自上游的 SetVariable / Clipboard.read / 文字识别等节点。属性面板的输入框里有灰色提示，照着写就行。

### 典型场景
- 在登录框里输入用户名密码
- 给聊天窗口发一句话
- 在搜索框里搜东西
- 把上游识别到的文字直接打进聊天框（连 `in_text` 端口）

### 防乱码推荐组合
```
kb_mode     = text
text        = 赫萝向汝问好~ 苹果今天新鲜吗？ 🍎
use_paste   = ✅ （默认就勾，推荐保留）
press_enter = ❌ / ✅ 看需不需要回车发送
```

**为什么 use_paste 推荐勾上？**
- 勾了：把文本写进剪贴板，Ctrl+V 粘贴，**毫秒级完成**，中文字符 100% 不会乱码
- 不勾：一个键一个键依次 SendInput，速度慢，部分系统没有中文输入法的话可能输入成 ???

> ⚠ 注意：粘贴模式会**覆盖剪贴板内容**（运行完不会自动还原，有需要的话前一步先 Clipboard.read 备份一下）。
> ⚠ 并行安全：粘贴 = 「写剪贴板 → Ctrl+V」两段，中间不能让别的分支插进来（否则会把别条分支的文本粘出去）。
> 所以这两步（含目标程序取走内容的那一拍）会持有**全局剪贴板锁**。并行分支里多条分支同时粘贴时会**依次排队**，
> 各自粘出自己的文本；代价是它们不会真正同时粘贴，而且**谁先粘不保证顺序**。

## 模式二：key（按键组合）

### 参数使用方式
右侧属性面板有**可视化的按键选择 UI**：
1. 点「➕ 添加按键」
2. 弹出的下拉菜单里选（ctrl / shift / alt / win / a~z / f1~f12 / 0~9 / 空格 / 回车 …）
3. 组合键自动拼成 chips，显示在面板里
4. 已经选中的键在下拉里**自动隐藏**，不会重复选；删除了又会重新出现

不用手填 key_combo JSON。

### 常见组合键
| 想按的键 | 组合键数组 |
|----------|------------|
| Ctrl + C 复制 | `["ctrl","c"]` |
| Ctrl + Shift + Esc 任务管理器 | `["ctrl","shift","escape"]` |
| Alt + F4 关闭窗口 | `["alt","f4"]` |
| Win + D 显示桌面 | `["win","d"]` |
| 单个 F5 刷新 | `["f5"]` |
| 连续按 10 次空格 | count=10，key_combo=`[" "]` |

### 拟人化时间参数
```
hold_ms     = 50   （每次按下保持 50ms，不用改）
interval_ms = 100  （两次之间停 100ms）
count       = 1    （按几次）
```
→ 这三项默认值就够，一般不用调。

## 典型用法

### 1. 登录账号（文本 + 组合键混搭）
```
# 节点1：PressKey(text)
use_paste = ✅
text      = {username}
press_enter = ❌

→ Tab 切换到密码框：PressKey(key)
  key_combo = ["tab"]

→ 节点2：PressKey(text)
text      = {password}
press_enter = ✅   ← 输入完密码直接回车登录
```

### 2. 游戏里按 5 次 Q 技能
```
kb_mode   = key
key_combo = ["q"]
count     = 5
hold_ms   = 80
interval_ms = 400
```

### 3. 截图保存
```
key_combo = ["win","printscreen"]   （Win10/11 自带全屏截图到「图片\屏幕截图」文件夹）
```

### 4. 把上游识别到的文字直接敲进去（用左侧端口）
```
连线：
  文字识别.text        → PressKey.in_text
  文字识别.out_done    → PressKey.in_exec

PressKey：
  kb_mode     = text
  text        = （留空，端口有值优先）
  use_paste   = ✅
  press_enter = ✅   ← 敲完直接回车发送
```
→ 识别出验证码 / 聊天内容后，直接替用户敲进当前光标处，不用手工中转。

## 常见问题

**Q：右侧「文本内容」支持变量吗？怎么用？**
→ 支持，写法 `{变量名}`，例如 `你好，{user_name}`；也支持 `${变量名}` 和 `{= 表达式 }`。运行时先算出真实文字再输入。
→ 注意：从左侧「文本内容」端口连线传进来的值**不会再做插值**——上游给什么就敲什么（它已经是算好的最终值）。

**Q：画布左侧那个「文本内容」端口什么时候用得上？**
→ 端口**一直都在**，切换模式它不会消失、连在上面的线也不会断。
→ 只有「输入模式 = 输入文本」时会被使用：有连线且值非空，就把上游的文字直接替你在目标窗口里打出来。
→ 「按键组合」模式不使用它（连了不生效），但线会保留；切回「输入文本」立刻又能用。

**Q：中文输入全是问号？**
→ 勾 `use_paste` 用粘贴模式，或者系统当前切到中文输入法。

**Q：某些快捷键没反应（比如 Ctrl+Alt+Del）？**
→ 安全相关的快捷键（Ctrl+Alt+Del、Win+L 锁屏）Windows 禁止程序模拟，按不了是正常的。其他都可以。

**Q：游戏里按了没反应？**
→ 有些反作弊驱动会屏蔽 SendInput。尝试以管理员身份启动蓝图软件；或者用「按键组合」模式试试（SendInput 底层的两种调用）。
