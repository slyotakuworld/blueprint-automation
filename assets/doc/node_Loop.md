# 🔁 Loop · 循环

> 循环跑圈儿~双击节点进入「循环体子画布」，把要重复的内容装进去，跑满次数或用「跳出循环」结束。不用再拉线回环啦。

---

## 节点外观

- **分类**：🧠 逻辑组件
- **配色**：紫 (#8250DF / #A371F7)
- **短名**：`loop`

---

## 端口

| 侧 | 类型 | 名称 | 标签 | 说明 |
|----|------|------|------|------|
| 输入 | ▶ 执行 | `in_exec` | ▶ | 进入循环 |
| 输出 | ▶ 执行 | `out_exit` | 退出 | 跑满次数 / 循环体内「跳出循环」后触发 |

> 💡 新模式：循环内容装在「循环体子画布」里（**双击 Loop 节点进入**），不再靠 `loop_body` 端口拉线回环。
> 旧蓝图里用 `loop_body` 端口拉线的写法仍然兼容，不会坏。

---

## 循环体子画布

双击 Loop 节点 → 进入一个独立的子画布，里面放「每圈要重复的节点」。

循环体子画布里有三个专用节点（进入子画布后，左侧节点库会多出它们）：

| 专用节点 | 作用 |
|----------|------|
| **再次循环** (Continue) | 跑到这里立即结束本轮、开始下一圈，不执行后面的节点 |
| **跳出循环** (Break) | 跑到这里立即结束整个循环，跳到 Loop 的「退出」出口 |
| （普通节点） | 自然走到子画布终点 = 本轮结束，进入下一圈 |

点左上角「← 返回父图」退出子画布，改动会自动存回 Loop 节点。

---

## 参数一览

| 参数名 | 编辑器 | 默认值 | 必填 | 说明 |
|--------|--------|--------|------|------|
| `infinite` | ✅ 复选 | `false` | - | 无限循环：勾选后忽略最大迭代，仅手动停止 / 跳出循环才能结束 |
| `max_iterations` | 整数 | `5` | ✅ | 最大迭代次数（1 ~ 10,000,000）；硬防死循环，无限循环模式下不生效 |
| `interval_sec` | 小数 | `1.0` | - | 每轮循环体跑完后的等待秒数（0.0 ~ 60.0） |

## 典型用法

### 1. 每 1 秒按一次 F5，按 100 次（子画布模式）

```
Loop 节点：
  infinite = ❌
  max_iterations = 100
  interval_sec = 1.0

双击 Loop 进入循环体子画布，放：
  Start → PressKey(按 F5 1次) → End

主图连线：
  Start → Loop.in_exec
  Loop.out_exit → [End]
```

### 2. 无限找图点击，找到「停止」就退出（子画布模式）

```
Loop：infinite = ✅

循环体子画布：
  Start → FindImage(找"停止"按钮)
          ├─ 命中 → Break(跳出循环)
          └─ 未命中 → Mouse(点击"继续") → End(本轮结束)

主图：
  Start → Loop → Loop.out_exit → ...
```

### 3. 带间隔的批量操作（每 30 秒看一次签到按钮）

```
Loop: max_iterations = 2880, interval_sec = 30
循环体子画布里放「签到」的判断 + 点击逻辑
```

## 常见问题

**Q：怎么退出循环？**
→ 三种方式：① 循环体里放「跳出循环 (Break)」节点；② 跑满 `max_iterations`；③ 蓝图工具栏 ⏹ 停止按钮。

**Q：旧蓝图用 `loop_body` 拉线回环的写法还能用吗？**
→ 能。只要 Loop 节点没有「循环体子画布」内容，就回退到旧的 `loop_body` 端口拉线行为，完全兼容。

**Q：循环体里某个节点失败了，会怎样？**
→ 子画布模式下，节点失败会中断当前这圈的执行流（和普通蓝图一致），但 Loop 仍会继续下一圈（除非你显式接了 Break）。
