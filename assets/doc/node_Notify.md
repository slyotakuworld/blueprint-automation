# 🔔 Notify · 通知

> 想提醒点啥就用咱~要么写在日志里，要么弹系统小窗口，还能放提示音，内容里塞变量也没问题哟。

---

## 节点外观

- **分类**：🎯 动作
- **配色**：深蓝 (#0B3A5C / #58A6FF)
- **短名**：`notify`

---

## 端口

### 输入
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `in_exec` | ▶ 执行 | ▶ | 上游触发 |
| `in_title` | ○ 数据 | 标题(连线优先) | 非空时，覆盖参数里的 `title` |
| `in_message` | ○ 数据 | 内容(连线优先) | 非空时，覆盖参数里的 `message` |

### 输出
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `out_exec` | ▶ 执行 | ▶ | 通知发完 → 触发下游 |

---

## 参数一览

| 参数名 | 编辑器 | 默认值 | 必填 | 说明 |
|--------|--------|--------|------|------|
| `title` | 文本 | `"通知"` | - | 通知标题。【优先级】in_title 连线非空 → 用连线值；否则用本参数。支持 {var} 插值 |
| `message` | 多行文本 | `""` | - | 通知正文。【优先级】in_message 连线非空 → 用连线值；否则用本参数。支持 `{var}` / `${var}` / `{= expr}` / `{ALL_VARS}` 展开所有变量 |
| `level` | 下拉 | `"INFO"` | - | 级别：INFO 信息 / WARN 警告 / ERROR 错误 / DEBUG 调试 |
| `duration_sec` | 小数 | `3.0` | - | 系统弹窗/通知显示持续时间（0.5 ~ 3600 秒） |
| `show_popup` | ✅ 复选 | `false` | - | 勾选：额外弹系统原生阻塞弹窗（打断用户注意，会阻塞蓝图直到关闭）；不勾选（默认）：右上角主窗口弹非阻塞浮动 Toast + 日志面板记录（不卡蓝图，推荐） |
| `play_sound` | ✅ 复选 | `false` | - | 勾选：播放系统提示音 |

---

## 级别效果

| level | 日志颜色 | 含义 |
|-------|----------|------|
| INFO | ⚪ 白色 | 普通信息（默认） |
| WARN | 🟡 黄色 | 警告 |
| ERROR | 🔴 红色 | 错误 |
| DEBUG | 🔵 蓝色 | 调试（详细信息，平时不建议开） |

---

## 典型用法

### 1. 变量变化时弹提示
SetVariable 设置完关键变量 → 接一个 Notify：
```
title   = 变量调试
message = 【当前变量快照】
{ALL_VARS}
level   = DEBUG
show_popup = ✅
```
→ 弹一个大对话框，把所有变量名+值全列出来，调试神器！

### 2. 找图失败非阻塞提示
FindImage.not_found → 接 Notify：
```
title   = ⚠️ 没找到
message = 找不到「开始按钮」，重试第 {retry_cnt} 次
level   = WARN
show_popup = ❌   （不阻塞，只在日志/右上角飘字）
play_sound = ✅
```

### 3. 蓝图完成提示
末尾接 Notify：
```
title   = ✅ 任务完成
message = 所有步骤跑完啦！用时 {elapsed} 秒，共点击 {click_cnt} 次
level   = INFO
show_popup = ✅
play_sound = ✅
```

## 常见问题

**Q：show_popup 勾了和没勾有啥区别？**
- **不勾（默认）**：蓝图不等待，立刻往下游 out_exec 继续。提示以"浮动 Toast + 日志"方式显示。**推荐**，90% 场景用这个。
- **勾了**：弹模态对话框，必须用户手动点"确定"关掉，蓝图才继续。适合紧急错误、必须人工确认的场景。

**Q：{ALL_VARS} 是什么？**
→ 特殊占位符，运行时自动展开成"变量名 = 值"的多行列表，调试时一把梭全部打印出来，不用一个个写 `{hp} {score} ...`。
