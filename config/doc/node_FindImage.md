# 🔍 FindImage · 找图

> 给咱一张参考图就在屏幕上找~在超时时间里反复试，找不到还能滚动鼠标页面后继续找；找到了可以顺手点一下，就算最后没找到，也会继续往下跑，下游靠「找到」信号自己判断就行啦。

---

## 节点外观

- **分类**：👁 视觉、感知
- **配色**：蓝 (#0969DA / #58A6FF)
- **短名**：`image`

---

## 端口

### 输入
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `in_exec` | ▶ 执行 | ▶ | 上游触发 |
| `in_template` | ○ 数据 (path) | 模板 | 非空时覆盖参数里的 template 路径 |
| `in_threshold` | ○ 数据 (float) | 阈值 | 非空时覆盖参数里的 threshold；出错时回退到 0.9 |

### 输出
| 名称 | 类型 | 标签 | 说明 |
|------|------|------|------|
| `out_exec` | ▶ 执行 | ▶ | 无论有没有找到，超时一到都会触发（下游自己用 out_found 做判断） |
| `out_pos` | ○ 数据 (tuple2) | 位置 | 找到时 = 模板中心 + offset 的最终坐标 (X,Y)；没找到 = None |
| `out_found` | ○ 数据 (bool) | 找到 | 找到了 = true，没找到 = false |

## 参数一览

| 参数 | 编辑器 | 默认值 | 说明 |
|------|--------|--------|------|
| `match_strategy` | 下拉 | `hybrid` | 匹配算法：智能混合 / 模板匹配 / 灰度匹配 / 特征匹配（详见下一节） |
| `search_mode` | 下拉 | `relative` | 找图范围：`relative` 相对目标程序（推荐）/ `absolute` 全屏 |
| `temp_target_title` | 文本 | `""` | 仅相对模式：临时目标窗口标题，不影响全局 |
| `temp_target_exe` | 文本 | `""` | 仅相对模式：临时目标程序名 |
| `temp_target_class` | 文本 | `""` | 仅相对模式：临时目标窗口类名 |
| `threshold` | 小数 | `0.9` | 匹配阈值（0.3 ~ 1.0），越高越严格，**全代码层统一默认 0.9** |
| `timeout_seconds` | 小数 | `10.0` | 超时秒数（0.5 ~ 600），在超时内反复重试 |
| `template` | 📁 路径 | `""` | 模板图片路径；右侧面板点「📸 截取目标」或「📂 导入图片」可快速填写 |
| `template_b64` | 文本 | `""` | 预览图 base64（只读，不用手填） |
| `scroll_dy` | 整数 | `0` | 滚动重试像素：0=不滚动；负=向前滚(页面向下翻)；正=向后(页面向上翻)。非0时，每轮找图失败后会滚动一次再重试，直到超时。 |
| `after_action` | 下拉 | `none` | 找到后执行：none 仅输出位置 / click 左键单击【推荐】/ double_click 双击 / right_click 右键 |
| `offset` | tuple2 | `(0,0)` | 点击偏移 (X,Y)。Y正=向下，Y负=向上。out_pos 输出的是偏移后的最终坐标 |
| `use_feature_assist` | 下拉 | `off` | 特征识别辅助：off 关闭 / verify 验证模式 / fallback 兜底模式 |
| `features_json` | 多行 | `"[]"` | 特征数据 JSON 数组（通过面板「✂ 从模板截取特征」自动生成） |
| `feature_tolerance` | 整数 | `15` | 特征位置验证像素容差（1~200），10~20 推荐 |
| `feature_min_hits` | 整数 | `2` | 最少命中特征数（1~20），至少 2 个才能做交叉验证 |
| `feature_capture_width` | 整数 | `0` | 自动记录不用手填 |
| `feature_template_w` | 整数 | `0` | 自动记录不用手填 |
| `feature_template_h` | 整数 | `0` | 自动记录不用手填 |

> 💡 **临时目标窗口 与「📸 截取目标」联动**：若已拾取临时目标窗口，点「📸 截取目标」时
> 框选范围会自动限定在该窗口内（窗口外点不进去、拖到边界自动贴边），
> 保证截出的模板确实取自这个窗口。找不到该窗口时回退为全屏框选并给出日志提示。

## 四种匹配算法

| 算法 | 中文 | 适用场景 | 抗变化能力 | 速度 |
|------|------|----------|-----------|------|
| **hybrid** | 智能混合【推荐】 | 大多数场景，兜底能力强 | 高 | 中 |
| template | 模板匹配(彩色BGR) | 尺寸固定、画面清晰、颜色稳定的 UI 按钮/图标 | 低（颜色/缩放/旋转一变就找不到） | 最快 |
| gray | 灰度匹配 | 颜色会变但形状不变的按钮（选中/未选中态） | 中（容忍颜色变化） | 快 |
| feature | 特征匹配(AKAZE) | 复杂画面、轻微旋转缩放、光照变化大 | 很高（经 RANSAC 几何验证） | 稍慢 |

### hybrid 智能混合的三层级联
1️⃣ 先跑彩色多尺度模板匹配（30 个尺度，0.8~1.2 覆盖）
2️⃣ 没找到 → 跑灰度多尺度模板匹配（30 个尺度）
3️⃣ 没找到 → 跑 AKAZE 特征点匹配（RANSAC 几何验证 + 固定最少 4 个内点才算成功）

→ 三层中**任意一层命中**就算找到，并在日志里标明是哪一层命中的（方便调阈值）。

## ✨ 测试匹配按钮（必看！）

右侧属性面板有个 **「测试匹配」** 按钮，调阈值必备神器：

### 特点
1. 点按钮会弹**模态进度条**，防止你在匹配过程中乱点
2. 进度条每处理 3 个尺度就刷新 UI（不会界面卡死）
3. **全局 DefaultScreenCapture 工具截屏幕**，和实际运行时用的截图工具完全一致
4. 严格按节点当前的匹配算法设置跑（hybrid就三级、template就只一层彩色，和运行时 100% 一样）
5. 结果弹窗里会告诉你：**命中了哪一层算法 / 得分 / 坐标 / 级联路径**（例如：`彩色→灰度→AKAZE`，表示前两层没找到最后用特征找到的）
6. 有**防重入标志**，连点不会并发执行
7. 任意提前退出分支都会清理临时文件、恢复窗口

→ 每张图第一次用，**先点一下测试匹配**再决定阈值设多少，不用每次都跑完整蓝图！

## 找图范围 search_mode

### relative 相对目标程序（推荐）
- 只截绑定窗口范围内的屏幕（避免跨窗口误匹配长得像的按钮）
- 输出坐标是相对窗口坐标，配合 Mouse relative 模式无缝点击
- 窗口从哪来：本节点的「临时目标」参数，或上游 BindWindow 节点绑定的窗口
  （主界面右上角「🎯 截图目标」下拉只用于编辑器取素材，**不参与蓝图运行**）

### absolute 全屏模式
- 截整个显示器屏幕
- 输出绝对屏幕坐标，Mouse 节点也要切到 absolute

## 特征识别辅助 use_feature_assist

在模板匹配之外，再用一张或多张小特征图做交叉验证：

| 模式 | 作用 |
|------|------|
| **off** | 不用特征辅助 |
| **verify 验证模式** | 模板匹配成功 → 再跑一遍特征辅助验证；特征也通过才算成功；更严格，减少误判 |
| **fallback 兜底模式** | 模板匹配失败 → 用特征辅助再试一次；找到了也算成功；更宽松 |

→ 特征辅助内部固定用彩色模板匹配，不受节点 match_strategy 选项影响。

→ 特征怎么加？右侧面板点 **「✂ 从模板截取特征」**，在预览图上框选小区域（比如按钮里的一个字母、一个小图标），至少框 2 个不同位置做交叉验证。

## 典型用法

### 1. 最常见：找到按钮就点一下
```
FindImage：
  template        = 截图按钮模板.png
  match_strategy  = hybrid 【推荐】
  search_mode     = relative
  threshold       = 0.9
  timeout_seconds = 10
  after_action    = click 【左键单击】
  offset          = (0, 0)
```
→ out_exec 会继续往下游，下游 VarSwitch 连 out_found = true 判断是否成功。

### 2. 找不到就滚一下页面再找（长列表场景）
```
FindImage：
  scroll_dy       = -400   ← 负=向前滚=页面向下翻，大约 1 页
  timeout_seconds = 20
  after_action    = click
```
→ 每轮找不到就滚 -400 像素，再重试，直到 20 秒超时。

## 常见问题

**Q：明明看到了却找不到？**
→ 第一步先点「测试匹配」：
- 如果显示「彩色匹配得分 0.78 < 阈值 0.9」→ 把阈值调低一点（0.85 左右）
- 如果彩色/灰度都没过、特征也没过 → 换个算法（用 feature），或者重新截一张更清晰的模板
- 另外检查窗口是不是被最小化/挡住了

**Q：误判（不是按钮却当成按钮）怎么办？**
→ 把 threshold 调高到 0.93+，或者开 use_feature_assist = verify 模式加特征交叉验证。

**Q：滚动方向经常搞反？**
→ 口诀：**负=页面向下翻**（滚到下面更多内容）。跟 pyautogui 的符号约定保持一致：
```
scroll_dy > 0 → 滚轮向前（朝屏幕外面转）→ 页面向上
scroll_dy < 0 → 滚轮向后（朝你手心转）→ 页面向下【想找列表下方东西，用负值！】
```

**Q：Y 轴 offset 方向跟 Mouse 一样吗？**
→ 一致：Y 正值 = 向下，Y 负值 = 向上。和 Mouse 节点 offset 参数约定保持一致，不用翻来覆去记。
