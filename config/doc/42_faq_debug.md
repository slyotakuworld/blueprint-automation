# 🔧 排错与调试 FAQ

> 跑不起来？点错位置？找图找不到？这里按「症状→原因→修复」整理了最常见的问题。

---

## 一、运行时立刻就停

### 症状 1.1：点运行后状态栏闪一下「运行中」，立刻变回「已停止」，没有任何节点执行。

> **99% 原因**：`Start` 节点的 `out_done ▶` 没有连到任何下游节点。

蓝图引擎的执行规则是：
```
触发端口（▶）必须有下游连接才会继续。
没有连接 → 认为这个分支结束了 → 整个蓝图没事情可做 → 立刻停止。
```

**修复**：
1. 确认 Start 的 `out_done ▶` 连到了下一个节点的 `in_exec ▶`
2. 如果还是没反应，选中连线 → 检查连接的端口是不是都是 ▶ 执行端口（○ 数据端口要连 ○，不能混）

---

### 症状 1.2：连了一条线但还是立刻停，日志提示「Port not found: xxx」

**原因**：端口连线引用的端口名和节点定义的端口名不一致（一般是旧蓝图文件改了节点定义但没同步）。

**修复**：把那条线删掉重新连一次。

---

## 二、鼠标/键盘操作没效果

### 症状 2.1：Mouse 节点执行了，鼠标却没动，或者跑到屏幕左上角 (0,0) 点了一下。

**排查步骤**：
1. **90% 是 BindWindow 没生效或者 coord_mode 错配**
   - FindImage search_mode = relative（输出相对坐标）
   - Mouse coord_mode = absolute（按绝对坐标去点）
   → 相对坐标 500,300 当成绝对坐标点 → 就点错了！
   → 两个节点**模式保持一致**（全 relative 或全 absolute）。

2. **目标窗口是不是最小化了？**
   - minimized / 被其他窗口全挡住了 → Mouse 就算点到了坐标点也没效果（点到空气上了）
   → 用 `BindWindow.ensure_foreground = ✅` 或者 Win+↑ 把窗口前置先。

3. **有没有以管理员身份运行？**
   - 部分 UAC 权限更高的窗口（系统设置、某些驱动界面），普通权限的程序 SendInput 按不进去
   → 右键 EXE / 右键 CMD 「以管理员身份运行」后再启动蓝图。

---

### 症状 2.2：PressKey 输入中文全是问号？

**原因**：逐键输入模式不支持中文（没有中文输入法或者输入法切换到英文了）。

**修复**：
```
PressKey 参数：
  kb_mode   = text
  use_paste = ✅ （勾上！）
```
→ 粘贴模式不走按键模拟，直接写剪贴板再 Ctrl+V，中文 100% 正确。

---

### 症状 2.3：Ctrl+C / Alt+F4 这种组合键按了没反应？

**排查**：
1. 组合键是否写对了？应该是 `["ctrl","c"]` 不是 `["ctrl + c"]`，也不是 `"ctrl+c"` 字符串。
2. 是不是按到了**安全快捷键**？Windows 不允许程序模拟：
   - Ctrl+Alt+Del
   - Win+L（锁屏）
   → 这几个任何程序模拟都没反应，是系统限制。
3. 是否先把焦点切到目标窗口了？
   → 先 BindWindow + 点一下目标窗口的空白区域，再按快捷键。

## 三、找图 / 图像相关

### 症状 3.1：FindImage 一直找不到，但是测试匹配能找到。

**原因**：测试匹配时截的屏幕和实际运行时屏幕**不完全一样**（窗口位置、DPI 缩放、UI 实际大小有差别）。

**排查步骤**：
1. 先点「测试匹配」按钮，看是哪一层级命中的：
   - 彩色命中得分 0.97 → 实际运行找不到 → 90% 是窗口 DPI 缩放变了
   → 在显示设置里把缩放锁定为 100%（推荐），或者改阈值 0.9→0.85
   - 灰度命中 → 改 match_strategy 成 gray，别用 template
   - 只有 AKAZE 命中 → 直接 match_strategy = feature，或者重截一张更清晰的模板

2. search_mode 对不对？
   - 实际运行时截图范围是整个屏幕？还是只截了窗口？
   → relative 模式：窗口跑位了也没关系；不绑窗口切 absolute 必错。

3. 模板图里是不是含了大片背景？
   → 重新截一张紧凑点的模板（只截按钮本体，四周少留空）。

---

### 症状 3.2：FindImage 找到了，但点到的位置偏了一点点。

**90% 原因**：relative / absolute 模式混用。

还有 10%：
- FindImage 找到的是**模板中心 + offset**
- offset 默认 (0,0) 是正中间
- 但有些按钮"真正可点的热区"不是正中心
→ 调 offset 一下（点击点往左偏就把 X 减 5~10，往上偏就把 Y 减 5~10）。

---

### 症状 3.3：IfImageDetect 一堆图检测好慢（每次好几秒）。

**优化**：
1. eval_mode 改成 `short_circuit` 或者 `or_true`，早停早返。
2. 参考图数组里的图，按「最可能先中」排前面。
3. 每张图都截得紧凑点，别太大。
4. match_strategy 能 template 就别 hybrid/feature。

---

## 四、声音 / 静止检测

### 症状 4.1：SoundDetect 立刻返回 yes/no，完全没等 timeout。

**检查**：
- detect_sound 模式：只要任何一瞬间超过阈值就算，所以如果当前环境里有连续的噪音（风扇、背景乐），采样第一帧就中 → 立刻 yes
→ 把 threshold_db 调大（更响的声音才算，-30 → -20）

- detect_silence 模式：当前环境本来就安静 → 第一帧就满足 → 立刻 yes

### 症状 4.2：SoundDetect 用 loopback 设备录不到声音？

**排查**：
1. 右下角音量图标右键 → 声音设置 → 确认你有「扬声器」默认播放设备
2. 有些老声卡驱动不支持 WASAPI 环回（loopback）。解决：
   - 用立体声混音（Stereo Mix）虚拟麦克风设备当 input
   - 或者直接 physical 物理线路连

## 五、循环 / 分支 / 变量

### 症状 5.1：Loop infinite 永远停不下来。

**正确用法**：
- infinite 模式必须有某个分支连到 `Loop.break_in ▶`（通常是 VarSwitch 满足条件 → break）
- 忘了连 break → 永远循环
- 临时停的话，工具栏点 ■ 停止按钮

### 症状 5.2：VarSwitch 条件明明满足了，但走的分支不对。

**检查**：
1. 变量类型：`hp` 是字符串 `"85"` 还是整数 `85`？
   - `str 85 < int 100` 在 Python 里**不报错**但顺序不可预测
   → 上游 SetVariable 统一类型：int/float/str 存进去是什么，比较时就要一致
2. 运算符用对了吗？
   - 字符串相等用 `==`；子串匹配用 `in`
   - 数字相等用 `==`，别不小心写 `=`

## 六、其他

### 症状 6.1：蓝图正常跑，但是 Notify 中文全是乱码或者弹窗没有按钮？

**排查**：
- sound_notify / toast 字体设置 → 系统没有对应的 fallback 字体
- 蓝图窗口 UI 本身中文正常 → 通常是第三方 toast 库（win10toast）对非 ASCII 文本支持不好
→ 临时解决方案：只在 Notify 里写英文，或者把「声音提示」勾上，靠蜂鸣声提醒。

### 症状 6.2：蓝图编辑器 Canvas 里节点拖不动？

**排查**：
1. 是不是点到了端口上（会开始拉线）？从节点中间空白处拖。
2. 是不是按了什么编辑键？Ctrl+Z 撤销一下看看。
3. 重启编辑器能解决 90% 的玄学问题。

---

## 七、终极万能三步 🍎

任何 bug 都先走一遍：
1. **看日志**（最后卡在哪一行？出错信息写的什么？）
2. **中间加 Notify**（前后都塞一个，看是哪一步死的）
3. **测试匹配按钮**（找图问题 90% 在这一步就能找到原因）

还不行？再来看进阶文档里的「性能优化与调试」一节，或者去反馈群提 Issue。
