# 🟢 Start · 开始

> 咱是整张蓝图唯一的起点哟~每张蓝图只能放一个咱，从这里开始往下跑！

---

## 节点外观

- **分类**：🧠 逻辑组件
- **配色**：GitHub 绿 (#238636 / #3FB950)
- **短名**：`start`

---

## 端口

| 侧 | 类型 | 名称 | 标签 | 说明 |
|----|------|------|------|------|
| 输入 | - | - | - | 无输入端口（起点嘛~） |
| 输出 | ▶ 执行 | `out_exec` | ▶ | 蓝图一启动，立刻从这里触发下游 |

---

## 参数

**无任何可配置参数。**

新建蓝图时会自动在画布上放一个 Start 节点，不用手动拖。

---

## 用法说明

1. **每张蓝图有且只有一个 Start**
   - 多了会报错（未来版本会自动禁用多余的）
   - 少了蓝图不知道从哪开始

2. **从 Start 开始连线**
   - Start 的 ▶ 输出 → 接到第一个执行节点
   - 典型链路：
     ```
     Start → OpenApp → Wait → BindWindow → FindImage → Mouse → PressKey → End
     ```

3. **调试时想从中间开始？**
   - 不用删 Start！
   - 在要开始的节点上点右键 → 「从该节点开始运行」

---

## 常见问题

**Q：Start 节点能被禁用吗？**
→ 理论上可以（右键→禁用节点），但禁用了之后蓝图没有起点，运行会立刻结束。别这么玩 🍎

**Q：我想蓝图启动后立刻先等几秒？**
→ Start → 连一个 Wait 节点，在 Wait 里设好等待秒数就行。
