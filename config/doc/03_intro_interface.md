# 🖼 界面总览

打开软件后，主界面分为 5 个区域，布局如下：

```
┌───────────────────────────────────────────────────────────────┐
│  ① 菜单栏 + 工具栏（新建/打开/保存/运行/暂停/停止）             │
├──────────┬──────────────────────────────┬──────────────────────┤
│          │                              │                      │
│  ②节点库  │       ③ 画布（蓝图编辑区）     │   ④ 属性检查器面板     │
│ (固定宽度) │                              │     (固定宽度)        │
│          │                              │                      │
│          │                              │                      │
├──────────┴──────────────────────────────┴──────────────────────┤
│  ⑤ 日志面板（运行输出 / 调试信息）                               │
└───────────────────────────────────────────────────────────────┘
```

> 💡 **固定宽度提示**：节点库面板和属性面板是**固定宽度**的，不支持拖拽调节，避免布局混乱。

---

## ① 顶部菜单栏 & 工具栏

### 菜单
- **文件**：新建蓝图、打开蓝图、保存、另存为、最近项目
- **编辑**：撤销 Ctrl+Z、重做 Ctrl+Y、删除 Delete、复制、粘贴
- **视图**：放大/缩小画布、重置视图、显示/隐藏面板
- **运行**：运行、暂停、停止（快捷键可在设置中自定义）
- **工具**：截图、设置

### 工具栏核心按钮
| 按钮 | 快捷键 | 功能 |
|------|--------|------|
| 🆕 新建 | Ctrl+N | 新建空白蓝图项目 |
| 📂 打开 | Ctrl+O | 打开已有蓝图 JSON |
| 💾 保存 | Ctrl+S | 保存当前蓝图 |
| ▶️ 运行 | 可配置 | 开始执行蓝图 |
| ⏸ 暂停 | 可配置 | 暂停正在运行的蓝图 |
| ⏹ 停止 | 可配置 | 立即终止蓝图执行 |

**工具栏右侧**（靠外一排）：
| 元素 | 功能 |
|------|------|
| 📦 导出 EXE | 把当前蓝图打包成可独立运行的 exe |
| 📚 文档攻略 | 打开内置使用手册 |

> ℹ️ 本版本已**移除**主界面右上角那个「🎯 截图目标」下拉（含旁边的 ↻ 刷新）。
> 目标窗口 100% 由蓝图自身决定：**BindWindow 节点**或各节点的**「临时目标」**参数——
> 这样编辑器里点▶运行与导出后的独立 EXE 行为完全一致。

## ② 节点库面板（左侧，固定宽度）

所有可用节点按 4 大类分组：
- 🚀 **应用控制**：OpenApp / BindWindow / WebBrowser / Command / HttpRequest
- 🧠 **逻辑组件**：Start / End / Loop / Sequence / SetVariable / VarSwitch / Clipboard / Notify
- 🎯 **执行动作**：Mouse / PressKey / Wait
- 👁 **视觉感知**：FindImage / IfImageDetect / StillnessDetect / SoundDetect

**操作**：点中节点 → 按住左键 → 拖到画布 → 松开

---

## ③ 画布区域（中间，蓝图编辑）

这是你拼蓝图的主战场！

### 画布操作
| 操作 | 效果 |
|------|------|
| 鼠标滚轮 | 缩放画布（以鼠标位置为中心） |
| 按住鼠标中键 / 空格 + 左键 | 平移画布 |
| Ctrl + A | 选中所有节点 |
| Delete | 删除选中的节点 / 线条 |
| Ctrl + Z / Ctrl + Y | 撤销 / 重做（包括线条删除！） |

### 节点交互
- 单击节点：选中（右侧显示属性），从该节点出发的线条会**高亮显示**
- 单击线条：线条变粗，**两端相连的节点会高亮**
- 拖动节点：线条会自动跟随刷新位置
- 右键节点 / 端口：弹出上下文菜单

---

## ④ 属性检查器面板（右侧，固定宽度）

选中节点后，这里显示该节点的**所有可配置参数**。

- 每个参数名旁边悬停会出现赫萝写的**黄色提示气泡**
- 数字输入框、下拉框都**禁用了滚轮**，避免悬停误改
- 坐标类参数右侧有 📍 按钮，点一下可以去屏幕上拾取
- 找图类节点有「📸 截取目标」和「测试匹配」按钮

### 测试匹配
找图节点的「测试匹配」按钮非常好用：
1. 先选好目标窗口、配好模板图
2. 点「测试匹配」
3. 会弹出进度条，赫萝会按照实际运行时的算法去屏幕上找
4. 结果会告诉你：用了哪层算法（彩色/灰度/特征）、得分多少、坐标在哪
5. 方便你调阈值，不用每次都跑完整蓝图

---

## ⑤ 日志面板（底部）

蓝图运行时所有输出都在这里：
- ✅ **INFO**：普通信息（绿色）
- ⚠ **WARN**：警告（黄色）
- ❌ **ERROR**：错误（红色）
- 🔍 **DEBUG**：调试信息（蓝色）

每个节点执行的开始 / 结束、找图得分、变量变化、命令输出…都会打印在日志里。

出问题先看日志，90% 的答案都在里面 🍎
