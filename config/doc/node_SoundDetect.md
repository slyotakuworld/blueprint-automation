# 🔊 SoundDetect · 声音检测

> 竖起耳朵听声音~要么等提示音响起来就满足，要么等环境彻底安静下来才算数，等太久就超时走no哟。

---

## 节点外观

- **分类**：👁 视觉、感知
- **配色**：青 (#00838f / #00acc1)
- **短名**：`if_sound`

---

## 端口

| 侧 | 名称 | 类型 | 标签 | 说明 |
|----|------|------|------|------|
| 入 | `in_exec` | ▶ 执行 | ▶ | 上游触发 |
| 出 | `yes` | ▶ 执行 | 满足 | 检测到目标条件（有声音/安静了） → 走这里 |
| 出 | `no`  | ▶ 执行 | 超时/不满足 | 超时了也没达到条件 → 走这里 |

---

## 参数一览

| 参数 | 编辑器 | 默认值 | 说明 |
|------|--------|--------|------|
| `device` | 文本 | `"default_loopback"` | 音频设备 ID。`default_loopback`=当前默认扬声器（录制系统播放的声音）；可从下拉框选择其他扬声器环回设备或麦克风 |
| `judge_mode` | 下拉 | `"detect_sound"` | 判断模式：detect_sound 检测声音 / detect_silence 检测静音 |
| `sample_ms` | 整数 | `500` | 单次采样时长毫秒（50~10000）；越长越准但一次检测越慢；detect_silence 建议 500~2000ms |
| `threshold_db` | 小数 | `-30.0` | 振幅阈值 dBFS（-90.0 ~ 0.0）；默认 -30dB≈人耳清晰可闻；调大（-10）必须很响才算；调小（-60）轻微响动也触发 |
| `timeout_seconds` | 小数 | `5.0` | 超时秒（0.0~600）；0=永不超时(慎用)；默认 5 秒内没满足条件就走 no |
| `debug_visual` | ✅ 复选 | `false` | 调试可视化：勾了后会在日志用 ASCII 字符画绘制采样波形 + 阈值线，方便调 threshold |

## 两种模式

### 1️⃣ detect_sound（检测声音）
"只要采样期间**任何时刻**声音超过阈值，就算触发"。
→ 适合：等某个提示音响起来（任务完成的「叮！」声、NPC 对话结束的音效…）。

### 2️⃣ detect_silence（检测静音）
"必须**整段采样时间**内所有时刻都低于阈值，才算触发"。
→ 适合：等环境彻底安静下来（CG 动画播完了、语音播报结束了、后台噪音停了…）。

## 音频设备 device

| 值 | 含义 | 典型场景 |
|----|------|----------|
| `default_loopback` | **默认扬声器（环回）** — 录制系统正在播放出去的声音，不是麦克风 | 想检测"游戏/视频里播放出的提示音"；90% 场景用这个！ |
| 其他 `xxx_loopback` | 指定某一个扬声器设备的环回 | 有多个扬声器输出的电脑 |
| `default_microphone` | 默认麦克风 | 想检测外界环境音（拍手、说话、蜂鸣器…） |
| 其他具体设备 ID 字符串 | 指定的麦克风/线路输入 | 接了专用音频线的自动化机柜 |

→ 直接从属性面板的下拉框点选，不用手填设备 ID 字符串。

## dBFS 阈值怎么调？

| threshold_db | 含义 | 你会听到什么才算 |
|--------------|------|----------------|
| `-60 dB` | 非常灵敏 | 几乎任何声音都触发（风扇响、硬盘转动…） |
| `-40 dB` | 比较灵敏 | 很轻的点击声、悄悄话音量 |
| `-30 dB` **默认** | 适中 | 人耳清晰可闻的正常音量（推荐） |
| `-20 dB` | 比较响 | 正常说话音量的提示音 |
| `-10 dB` | 非常响 | 系统警告声、大音量音乐才能触发 |

→ 不知道设多少合适？先**开 debug_visual** 跑一次，看日志里的 ASCII 波形，再根据实际情况调。

## 典型用法

### 1. 等「任务完成叮一声」再点下一步
```
SoundDetect：
  judge_mode     = detect_sound
  device         = default_loopback
  threshold_db   = -28.0   （比默认稍敏感一点，叮一下不算特别大）
  sample_ms      = 1000    （1 秒采样足够捕捉"叮"）
  timeout_seconds = 60     （最多等 1 分钟）

连线：
  yes → 响起来了 → Mouse 点「下一页」
  no  → 超时了可能被卡住了 → Notify + 暂停蓝图
```

### 2. 等一段长语音/动画完全播完
```
SoundDetect：
  judge_mode     = detect_silence
  sample_ms      = 1500    （必须连续 1.5 秒都安静才算完，避免中间停顿误判）
  threshold_db   = -35
  timeout_seconds = 300

yes → 声音停了，继续下一个任务
```

### 3. 调试 threshold 用 ASCII 波形
第一次用先开 debug_visual 跑一次：
```
SoundDetect：
  debug_visual = ✅
```
→ 日志里会打印类似：

→ 一眼看到实际声音的 dB 值，再把 threshold_db 调到合适位置。

## 常见问题

**Q：default_loopback 什么意思？为什么听不到麦克风的声音？**
→ 环回设备（loopback）录制的是"系统扬声器播出去的声音"，相当于"内录"。
如果你想录麦克风（比如"拍手触发"），device 要选 `default_microphone`。

**Q：一直触发不了？**
→ 先开 debug_visual，看波形是不是特别平（-80dB 那种）；如果是，就说明 device 选错了或者系统播放音量开太小。

**Q：总是误触发？**
 threshold_db 调大一些，比如从 -30 调到 -22，只有更响的声音才算。detect_sound 模式下 sample_ms 也可以调大一点，要求采样期间"持续有声"再触发（目前 detect_sound 是有一瞬间响就算；未来会加持续时长参数）。

**Q：detect_silence 播放音乐时却判定为静音？**
 先确认 device 选的是 `default_loopback`（录系统播放的声音），不是麦克风。如果 soundcard 库没安装，系统音频采集会失败。运行 `pip install soundcard` 后重启软件。detect_silence 需要连续 2 个采样窗口都低于阈值才判定，避免偶然静音误触发。

**Q：timeout_seconds 设 0 永不超时，怎么停止？**
→ 工具栏 ■ 停止按钮手动停止蓝图。未来版本会加其他节点主动中断 SoundDetect 的机制。
