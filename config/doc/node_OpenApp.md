# 🚀 OpenApp · 启动程序

> 帮汝打开外部程序~告诉咱程序在哪、要传啥参数，启动成功就继续，开不起来就走失败分支。

---

## 节点外观

- **分类**：🚀 应用控制
- **配色**：紫 (#8957E5 / #BC8CFF)
- **短名**：`open_app`

---

## 端口

| 侧 | 类型 | 名称 | 标签 | 说明 |
|----|------|------|------|------|
| 输入 | ▶ 执行 | `in_exec` | ▶ | 上游触发后开始启动程序 |
| 输出 | ▶ 执行 | `out` | 成功 | 程序启动成功（且等待时间过完）→ 往下走 |
| 输出 | ▶ 执行 | `fail` | 失败 | 程序路径不存在 / 权限不足 / 启动超时 → 走这里 |

> 💡 启动成功与否的判断：只要系统 API 创建进程没报错，就算「成功」。程序自己打开后崩溃，属于后续逻辑，本节点不会感知。

---

## 参数一览

| 参数名 | 编辑器 | 默认值 | 必填 | 说明 |
|--------|--------|--------|------|------|
| `path` | 📁 路径选择 | `""` | ✅ | 要启动的可执行文件路径（.exe / .bat / .lnk 快捷方式 都行） |
| `args` | 文本输入 | `""` | - | 命令行启动参数（空格分隔，支持变量插值） |
| `working_dir` | 📁 路径选择 | `""` | - | 程序的「工作目录(CWD)」；留空=自动用程序所在目录 |
| `wait_sec_after_launch` | 小数 | `2.0` | - | 启动后等待的秒数（0.0 ~ 120.0），给程序留点启动时间再往下走 |

---

## 典型用法

### 1. 打开记事本
```
path = C:\Windows\notepad.exe
args = （留空）
wait_sec_after_launch = 1.5
```
→ 打开空白记事本，等 1.5 秒后下一个节点继续（比如输入文字）。

### 2. 打开 Chrome 访问指定网址
```
path = C:\Program Files\Google\Chrome\Application\chrome.exe
args = https://www.baidu.com
wait_sec_after_launch = 3.0
```
→ 会自动把网址作为参数传给 Chrome。

### 3. 路径里用变量
```
path = {game_path}
args = --window-mode --width {w} --height {h}
```
→ `{game_path}` 等变量由上游 SetVariable 节点先设置好。

## 常见问题

**Q：找不到程序路径怎么办？**
→ 右键桌面快捷方式 → 属性 → 「目标」里的完整路径复制过来。或者用「浏览」按钮选。

**Q：启动了但后面节点不生效？**
→ 多半是 `wait_sec_after_launch` 太短，程序还没完全加载好。调大一点（游戏可以设 10 秒以上）。

**Q：可以打开 .bat 批处理 / .py 脚本吗？**
→ 可以。.bat 直接选就行；.py 脚本建议 path 填 python.exe，args 填 `脚本路径.py 参数`（不然有时候双击能跑，这里启动不行，因为文件关联可能不完整）。

**Q：想让程序启动后蓝图立刻往下走，不等它启动完？**
→ `wait_sec_after_launch = 0` 即可。
