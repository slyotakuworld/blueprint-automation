# 🔗 BindWindow · 绑定窗口

> 告诉咱要操作哪个窗口~标题、程序名、类名这仨条件填了就得全对上才算配对成功，绑好之后后面的截图、点击、找图都会自动对准这个窗口的坐标哒。

---

## 节点外观

- **分类**：🚀 应用控制
- **配色**：紫 (#8957E5 / #A371F7)
- **短名**：`bind_win`

---

## 端口

| 侧 | 类型 | 名称 | 标签 | 说明 |
|----|------|------|------|------|
| 输入 | ▶ 执行 | `in_exec` | ▶ | 上游触发 |
| 输出 | ▶ 执行 | `success` | 成功 | 找到匹配的窗口并绑定成功 → 走这里 |
| 输出 | ▶ 执行 | `fail` | 失败 | 未找到符合条件的窗口 → 走这里（只查找一次，无超时重试） |

---

## 参数一览

| 参数名 | 编辑器 | 默认值 | 必填 | 说明 |
|--------|--------|--------|------|------|
| `title` | 文本 | `""` | - | 窗口标题（子串匹配即可，不用完全一样） |
| `exe_name` | 文本 | `""` | - | 程序名，比如 `notepad.exe`、`chrome.exe`（子串匹配） |
| `class_name` | 文本 | `""` | - | 窗口类名（精确匹配，不常用，用工具获取） |
| `resolution_w` | 整数 | `0` | - | 归一化宽度；0=自动探测窗口实际宽 |
| `resolution_h` | 整数 | `0` | - | 归一化高度；0=自动探测窗口实际高 |

---

## 存储的全局变量

绑定成功后，以下 7 个变量会自动写入全局变量表，下游所有节点都能用 `{变量名}` 引用：

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `{target}` | dict | 完整的目标信息字典（含 hwnd/title/rect/resolution_ref） |
| `{target_hwnd}` | int | 窗口句柄（Windows HWND） |
| `{target_title}` | str | 窗口标题文本 |
| `{target_x}` | int | 窗口左上角 X 坐标 |
| `{target_y}` | int | 窗口左上角 Y 坐标 |
| `{target_w}` | int | 窗口宽度（像素） |
| `{target_h}` | int | 窗口高度（像素） |

> 🐺 咱的提醒：如果绑定失败（走 fail 分支），这些变量不会被更新，保留上一次的值或不存在。用 `{target_title}` 在 Notify 里显示当前绑定的窗口名是个好习惯~

## 为什么要绑定窗口？

绑了之后：
- 找图/截图的**默认范围** = 只截这个窗口，不会误截别的窗口里长得像的按钮
- **鼠标坐标自动换算**：比如你是在 1920×1080 的窗口尺寸下录的坐标，用户窗口缩放成 1600×900，依然点在正确的相对位置

游戏自动化**强烈建议**在蓝图开头先 BindWindow 一次~

## 典型用法

### 1. 绑定记事本
```
title    = 无标题 - 记事本
exe_name = notepad.exe
class_name = （留空）
```
→ 两个条件同时满足才算匹配到，避免有个叫「记事本使用说明.txt」的窗口误匹配。

### 2. 只按程序名绑定（不在乎标题）
```
title    = （留空）
exe_name = genshinimpact.exe
```
→ 只要是这个 exe 开的窗口，不管标题叫啥都绑。

### 3. 用主界面右上角下拉绑定
其实更常用的做法是：
1. 先手动打开目标程序
2. 主界面右上角「目标程序」下拉列表里选它（会自动列出所有窗口）
3. 后面找图节点的「相对目标程序」模式就自动基于这个窗口

BindWindow 节点适合在**蓝图开头强制指定**，防止用户忘记选下拉。

## 常见问题

**Q：怎么知道一个窗口的 title/exe/class？**
→ 主界面「工具 → 窗口信息拾取器」，用十字准星拖到目标窗口上，三项全显示出来，复制粘贴到参数里就行。

**Q：找不到窗口一直 fail？**
→ 多半是程序还没启动完，在 BindWindow 前面加个 Wait 节点等几秒。或者把启动、绑定放一块：OpenApp → Wait(5s) → BindWindow。

**Q：绑好了但窗口最小化了，找图还能找到吗？**
→ 找不到，截图需要窗口可见。窗口最小化的话，蓝图开头先还原窗口（未来版本有「激活窗口」节点，临时方案：用 Mouse 节点点任务栏图标，或者 Command `start "" "..."`）。
