# 🔁 Loop · 循环

> 循环跑圈儿~要么到了设定的最大次数就退出，要么勾上「无限循环」就一直跑（只能暂停/停止），每轮之间还能等一小会儿再跑下一圈哟。

---

## 节点外观

- **分类**：🧠 逻辑组件
- **配色**：紫 (#8250DF / #A371F7)
- **短名**：`loop`

---

## 端口

| 侧 | 类型 | 名称 | 标签 | 说明 |
|----|------|------|------|------|
| 输入 | ▶ 执行 | `in_exec` | ▶ | 进入循环 |
| 输出 | ▶ 执行 | `loop_body` | 循环体 | 每一圈开头都会触发，接循环内容 |
| 输出 | ▶ 执行 | `out_exit` | 退出 | 跑到最大次数（或手动break，未来版本）后触发 |

> 💡 连接方式：`loop_body` → 接你要重复跑的一串节点 → 这串的末尾再 **连回 Loop 的 `in_exec`**，就闭合啦！或者简单场景不用连回，直接 `loop_body` 跑一次就当一圈，Loop 内部自己计数。

---

## 参数一览

| 参数名 | 编辑器 | 默认值 | 必填 | 说明 |
|--------|--------|--------|------|------|
| `infinite` | ✅ 复选 | `false` | - | 无限循环：勾选后忽略最大迭代，仅手动停止 / 暂停才能结束 |
| `max_iterations` | 整数 | `5` | ✅ | 最大迭代次数（1 ~ 10,000,000）；硬防死循环，无限循环模式下不生效 |
| `interval_sec` | 小数 | `1.0` | - | 每轮循环体跑完后的等待秒数（0.0 ~ 60.0） |

---

## 典型用法

### 1. 每 1 秒按一次 F5，按 100 次
```
Loop 节点：
  infinite = ❌
  max_iterations = 100
  interval_sec = 1.0

连线：
  Start        → Loop.in_exec
  Loop.loop_body → PressKey(按 F5 1次)
  (可选：PressKey 末尾再接回 Loop.in_exec，效果一致)
  Loop.out_exit → [End]
```

### 2. 无限循环找图点击（游戏日常挂机）
```
Loop 节点：
  infinite = ✅
  interval_sec = 2.5

连线：
  Start → Loop
  Loop.loop_body → FindImage(找"开始战斗"按钮) → Mouse(点击) → (接回 Loop 或不接都行)
```
→ 每 2.5 秒跑一圈找图，点 ■ 停止按钮。

### 3. 带间隔的批量操作（每 30 秒看一次签到按钮）
```
Loop:
  max_iterations = 2880   (24 小时 × 3600 / 30)
  interval_sec    = 30
```

## 常见问题

**Q：怎么退出无限循环？**
→ 蓝图工具栏的 ⏹ **停止按钮** 直接停。未来版本会加「退出循环」节点和条件 break。

**Q：循环体中间某个节点失败了，还会继续下一圈吗？**
→ 看你自己的连线。如果那个节点有 `err` 失败分支没接任何东西，这条执行链路就断了，Loop 不会收到下一次的 in_exec，就停在那里了。
解决方案：把失败分支也接回 Loop.in_exec（或者接 Notify 提示然后再接回去）。

**Q：Loop 怎么知道「跑完一圈」了？**
→ 两种方式都能触发 +1 计数：
1. loop_body 下游链路最终接回了 Loop.in_exec → 算一圈
2. loop_body 触发后，经过 interval_sec 时间，内部自动 +1 → 算一圈（简单场景不用连回也行）
